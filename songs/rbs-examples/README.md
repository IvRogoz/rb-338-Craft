Sample original ReBirth songs for importer verification, downloaded from
[Peff's ReBirth archive](https://github.com/peffre/ReBirth-RB-338/tree/main/ReBirth%20Song%20Files)
and its [Keyboard Magazine examples](https://github.com/peffre/ReBirth-RB-338/tree/main/ReBirth%20of%20the%20Cool-KeyboardMagazine/examples).

Open **SONG / FILE · LIBRARY** at the top of the app, then use **IMPORT** to select any of the three files.
